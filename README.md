# KAIROS SUPPORT

Panasonic **KAIROS** の設定を、Blackmagic Design ATEM のような
「誰でも触れる」UI/UX で行うためのサポートアプリ。

KAIROS はレイヤー合成・IP 入出力・マクロと非常に自由度が高い一方、
設定がマクロ／スクリプト的で、現場で気軽に触りづらい面があります。
このアプリはその間に立って、**画面で組み立てた操作を KAIROS のコマンドに翻訳する**
ことを目指します。

## 現在の状態

アプリのモックアップ（クリック可能な HTML プロトタイプ）が入っています。
実機とは通信しません。すべて画面上のダミー状態です。

```
mockup/index.html    ← ブラウザで開くだけで動きます
docs/concept.md      ← 画面構成と設計方針
```

## モックアップでできること

| 画面 | 内容 |
| --- | --- |
| **Switcher** | PGM / PVW バス、T バー、AUTO / CUT、シーンとレイヤースタック、キー、スナップショット |
| **Sources** | 入力一覧（12G-SDI / NDI / ST 2110 / メディア / SRT）と状態、並べ替えアシスト |
| **Multiview** | レイアウト選択とペインへのソース割り当て、タリー枠・音声メーター |
| **Macro** | **ブロックを並べてマクロを作り、KAIROS コマンドを自動生成** |
| **Panel** | KAIROS Control のキーに機能を貼り付ける |
| **Audio** | フェーダー、AFV の対応表、出力ルーティング |

画面下の**コントロールサーフェス（PGM / PVW バス＋トランジション）は常時表示**で、
どの画面にいてもすぐ画を切り替えられます。ATEM Software Control の
「バスが常に見えている安心感」を KAIROS のシーン／レイヤー概念に載せています。

### 触ってみるところ

- PGM / PVW のキーを押す → タリーとモニターが変わる（マルチビューにも反映）
- 効果を WIPE / DVE にして **AUTO** か **T バー** → トランジションが変わる
- **Macro** 画面で左のブロックを押して追加 → 右の「生成コマンド」がその場で更新
- ステップの丸いパラメーター（`PVW バス` `0.5 秒` など）を押すと値が切り替わる

## 設計の考え方

1. **プログラミングに見せない** — マクロは文字列ではなくブロックの並び。
   生成されたコマンドは「確認用」に見せるだけで、書くのは画面。
2. **常にバスが見えている** — 設定画面に入っても本線を見失わない。
3. **KAIROS の語彙は残す** — シーン／レイヤー／AUX といった呼び名は変えない。
   変えるのは *組み立て方* であって、機器の考え方ではない。
